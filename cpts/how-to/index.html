How do I…?.

Initial access & services

  • Turn an open service into a shell Go from "a port is open" (or "I have a credential") to running commands on the box.
  • Move files on and off the box Upload a tool to the target, or pull loot back, on Windows or Linux — including when there's no internet.

Windows host

  • Pass-the-Hash (PtH) Authenticate as a user with their NT hash — no password, no cracking — and get a shell or run commands.
  • Dump credentials from LSASS Pull plaintext passwords, NT hashes and Kerberos tickets out of the LSASS process on a Windows host.
  • Dump local hashes from the SAM Recover the local account NT hashes from a Windows host's SAM database.

Linux host

  • Hunt credentials on a Linux host Find reusable passwords, keys and hashes already sitting on a Linux box you've landed on.
  • Escalate to root on Linux Go from a standard user to root using the common local misconfigurations.

Active Directory

  • Pass-the-Ticket (from Windows) Reuse a Kerberos ticket (TGT or TGS) on a Windows host to authenticate as its owner.
  • Pass-the-Ticket (from Linux) Use a Kerberos ticket from a Linux attack box (or one looted off a Linux host) to authenticate across the domain.
  • Pass-the-Certificate Turn a user or machine certificate (PFX) into a Kerberos TGT and their NT hash via PKINIT.
  • Roast Kerberos (Kerberoast & AS-REP) Pull crackable Kerberos hashes for service and pre-auth-less accounts with only one low-priv credential (or none).
