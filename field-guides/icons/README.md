# Vendor architecture icons

Official icons from each vendor's published architecture icon set, used in the
field guide diagrams (`{aws/lambda}` in a guide's `sequence`, `flow` or
`layers` block; see `scripts/lib/guide-visuals.mjs`). Only the icons the
diagrams use are kept here, unmodified apart from stripping XML comments and
metadata. They represent the vendors' own products and are used under the
vendors' terms for architecture diagrams and documentation:

| Folder | Source | Terms |
| --- | --- | --- |
| `aws/` | AWS Architecture Icons, package of 31 July 2026 (aws.amazon.com/architecture/icons) | AWS allows customers and partners to use the icons to create architecture diagrams |
| `azure/` | Azure Public Service Icons V24 (learn.microsoft.com/azure/architecture/icons) | Microsoft permits their use in architectural diagrams, training materials and documentation |
| `entra/` | Microsoft Entra architecture icons, October 2023 (learn.microsoft.com/entra/architecture/architecture-icons) | As above |
| `gcp/` | Google Cloud core product icons (cloud.google.com/icons) | Google's product icons may be used to refer accurately to its technology, for instance in architecture diagrams |

Don't crop, recolour or distort them, and don't use them for anything other
than the product they stand for. Other vendors in the guides (Okta,
CrowdStrike, Sophos, Darktrace, Starlink) publish no diagram icon set, so those
diagrams use the site's own icons and the vendor's brand colours only.
