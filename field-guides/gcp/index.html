The mental model

Access is granted by IAM bindings (principal + role) on a resource, and they inherit down the hierarchy. A role granted on a folder applies to every project in it.

Organization
The root node, tied to a Workspace or Cloud Identity domain. Org policies set guardrails here.
Folder
Groups projects (by team or environment). Bindings here reach every project below.
Project
The unit of billing, APIs and IAM. Has a project ID (acme-prod) and a project number (123456789012).
Principal
Who: user:, group:, serviceAccount:, domain:, or the public allUsers / allAuthenticatedUsers.
Role
A bundle of permissions. Basic (roles/owner, roles/editor, roles/viewer), predefined, or custom.
Binding
One principal plus one role on one resource. A resource's IAM policy is a list of bindings.
Service account
A non-human identity, written as an email. Workloads run as one.
Service account key
A long-lived JSON private key for a service account. The GCP equivalent of a leaked AWS AKIA key.
Workload Identity Federation
Lets external identities (AWS, GitHub Actions, Entra) get short-lived GCP tokens with no keys.
Org policy
Constraints such as "no service account keys" or "no public buckets", inherited down the tree.

Service accounts and impersonation

How impersonation works

roles/iam.serviceAccountTokenCreator
Lets a principal mint tokens as a service account. Holding it is as good as being that account.
roles/iam.serviceAccountUser
Lets a principal attach a service account to a VM or function. That workload then acts as the account.
roles/iam.serviceAccountKeyAdmin
Lets a principal create keys: long-lived persistence.
Delegation chain
serviceAccountDelegationInfo in the audit log lists who impersonated whom.

Who really did it?

Cloud Storage

Bucket
Global container: gs://acme-exports. Name is unique across all of GCP.
Object
A file in a bucket. "Folders" are name prefixes.
Uniform bucket-level access
IAM only, no per-object ACLs. The recommended setting.
Public access prevention
Blocks allUsers / allAuthenticatedUsers grants, even by an owner.
Signed URL
Time-limited access to one object for anyone holding the link, signed with a service account key.
Data Access logs
Object reads and writes. Off by default for Cloud Storage: turn them on before you need them.

Serverless and compute

Cloud Functions / Cloud Run
Serverless code and containers. 2nd-gen functions run on Cloud Run.
Invoker binding
roles/run.invoker or roles/cloudfunctions.invoker. Granted to allUsers, the endpoint is public.
Runtime service account
The identity the code runs as. Its tokens come from the metadata server.
Environment variables
Config, and too often secrets. Prefer Secret Manager.
Startup script / metadata
Instance metadata can hold startup scripts and SSH keys. Changing it is persistence.
OS Login / project-wide SSH keys
How SSH keys reach VMs. setCommonInstanceMetadata adds keys to every VM in the project.

Metadata server: getting a token

Read: the metadata server lives at metadata.google.internal (169.254.169.254).

Containment

Disable a leaked service account key

bashgcloud iam service-accounts keys disable KEY_ID --iam-account=deploy-bot@acme-prod.iam.gserviceaccount.com

Disable the service account entirely

bashgcloud iam service-accounts disable deploy-bot@acme-prod.iam.gserviceaccount.com

Tune: disabling breaks every workload using the account. Existing ya29 tokens can live for up to an hour.

Remove public access from a bucket

bashgcloud storage buckets remove-iam-policy-binding gs://acme-exports --member=allUsers --role=roles/storage.objectViewer
gcloud storage buckets update gs://acme-exports --public-access-prevention

Preserve a VM disk

bashgcloud compute disks snapshot web-1 --zone=europe-west2-a --snapshot-names=ir-case-1234-web-1

Hunting in SecOps

Service account keys created

udmmetadata.log_type = "GCP_CLOUDAUDIT"
metadata.product_event_type = "google.iam.admin.v1.CreateServiceAccountKey"

IAM policy changes

udmmetadata.log_type = "GCP_CLOUDAUDIT"
metadata.product_event_type = /SetIamPolicy$/

Tune: field mappings depend on the parser version. Check one event in the UDM viewer first.
