The mental model

Proofpoint Email Protection is the gateway (often Proofpoint on Demand, PoD). Targeted Attack Protection (TAP) adds URL Defense and Attachment Defense, and reports every threat delivered, blocked, clicked or stopped. TRAP pulls delivered threats back out of mailboxes.

Email Protection (PPS / PoD)
The gateway: spam, virus, policy, impostor classification. Proofpoint on Demand is the hosted version.
TAP
Targeted Attack Protection: URL Defense, Attachment Defense, and the dashboard and SIEM API that report threats.
URL Defense
Rewrites URLs to urldefense.com and checks them at click time.
Attachment Defense
Sandboxes attachments before or after delivery.
Threat ID
A stable ID for one threat (a URL or attachment) in TAP. Pivot on it to find every message carrying it.
Classification
malware, phish, spam, impostor (BEC).
VAP
Very Attacked People: the users TAP sees targeted most. Watch their accounts harder.
TRAP
Threat Response Auto-Pull: removes delivered messages that are later found malicious, and follows forwards.
Smart Search
Message trace in the Email Protection console.

A rewritten link

Read: in v3 links the original URL is readable between the __ markers. Some characters are moved into the token part, so decode with Proofpoint's decoder before searching on the exact URL.

Containment

GoalHow
Pull delivered messagesTRAP (automatic, or a manual pull by message ID)
Stop more arrivingBlock the sender or domain in an Email Protection policy
Stop clicks workingBlock the URL or domain in URL Defense
Contain a compromised userReset password, revoke sessions, remove malicious inbox rules

Hunting in SecOps

Permitted clicks

udmmetadata.vendor_name = "Proofpoint" nocase
target.url != ""
security_result.action = "ALLOW"
$user = principal.user.email_addresses
match:
  $user
outcome:
  $clicks = count(metadata.id)
  $urls = array_distinct(target.url)
order:
  $clicks desc

Delivered threats by classification

udmmetadata.vendor_name = "Proofpoint" nocase
metadata.event_type = "EMAIL_TRANSACTION"
$class = security_result.category_details
match:
  $class
outcome:
  $messages = count(metadata.id)

Tune: TAP and the Email Protection message logs arrive as separate feeds in SecOps. Check one event of each in the UDM viewer first.
