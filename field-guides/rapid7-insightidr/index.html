The mental model

Logs come in two ways: the Insight Agent on endpoints, and event sources (domain controllers, DHCP, firewalls, VPN, cloud apps) read by an on-premises Collector or pulled from cloud APIs. InsightIDR's cloud parses each event into a log set, then attributes it: which asset had that IP at that time (from DHCP and agent data), and which user was on that asset (from authentication). Detections and searches run on the attributed data.

Insight Agent
The endpoint agent shared with InsightVM. Sends process starts, logons and endpoint events, and runs containment jobs.
Collector
An on-premises server that receives syslog and polls event sources, then forwards to the cloud.
Event source
One configured feed: a DC's security log, a DHCP server, a firewall, a cloud app.
Log set
The parsed category events land in (Asset Authentication, Firewall Activity). Searches start from one or more log sets.
Attribution
Linking an IP to an asset (DHCP, agent) and an asset to a user (logons). Wrong or missing DHCP data makes alerts land on the wrong person.
ABA
Attacker Behaviour Analytics: Rapid7's detections for attacker techniques, mostly on endpoint and network data.
UBA
User Behaviour Analytics: detections on user activity (new country, impossible travel, spoofed domain, privilege changes).
Detection rule actions
Each rule creates investigations, only alerts, or is off, with a priority you can tune per rule.
Investigation
The case: alerts, evidence, assignee, status (Open, Investigating, Waiting, Closed) and a disposition.
Deception
Honeypots, honey users, honey credentials and honey files. Any touch is a high-confidence alert.

Read: if a log set is empty, the event source behind it is down or misparsed. Check Data Collection before you trust a search that finds nothing.

LEQL for Log Search

WantLEQL
Equalswhere(destination_account = "jsmith")
Case-insensitivewhere(destination_account = NOCASE("JSmith"))
One of severalwhere(process.name IIN ["cmd.exe", "powershell.exe"])
Containswhere(process.cmd_line ICONTAINS "-enc")
Starts withwhere(destination_asset STARTS-WITH "srv-")
Regexwhere(process.cmd_line = /.*\s-e(nc)?\s.*/i) (a field regex must match the whole value; where(/x/i) searches the whole event)
Notwhere(result != "SUCCESS") or where(NOT ...)
Count by groupgroupby(source_ip) calculate(count)
Distinct countgroupby(source_ip) calculate(unique:destination_account)
Over timecalculate(count) timeslice(1h)
Top valuesgroupby(destination_asset) limit(20)
Sortsort(desc) (on the calculated value)

Tune: field names come from the parsed event, so they differ between log sets. Open one event in Log Search and click a field to add it to the query rather than typing it.

Containment

GoalHow
Isolate a hostQuarantine the asset (Insight Agent). It keeps talking to Rapid7 only. Unquarantine from the same place
Stop a processKill process from the investigation or the asset page (Insight Agent)
Collect evidenceVelociraptor (integrated with the agent) or an InsightConnect collection workflow
Disable a userInsightConnect workflow to Active Directory, Entra ID or Okta: disable, reset password, revoke sessions
Block an indicatorInsightConnect workflow to the firewall, proxy or EDR; add it to a threat feed in InsightIDR

Watch for: quarantine needs a healthy agent. A host whose agent stopped checking in won't receive the job; check the asset's last seen time first.

Queries

Password spray: many users from one source (Ingress Authentication)

leqlwhere(result != "SUCCESS")
groupby(source_ip)
calculate(unique:user)
sort(desc)
limit(20)

Encoded PowerShell (Process Start Events)

leqlwhere(process.name IIN ["powershell.exe", "pwsh.exe"] AND process.cmd_line = /.*\s-e(nc|ncodedcommand)?\s+[A-Za-z0-9+\/=]{40,}.*/i)

Logons to many hosts from one account (Asset Authentication)

leqlwhere(result = "SUCCESS" AND logon_type IIN ["NETWORK", "REMOTE_INTERACTIVE"])
groupby(destination_account)
calculate(unique:destination_asset)
sort(desc)

Rare processes (Process Start Events)

leqlgroupby(process.exe_path)
calculate(unique:hostname)
sort(asc)
limit(50)

Tune: check the exact field names (user or destination_account, hostname or asset) on one event in your log set first: they differ between event sources.
